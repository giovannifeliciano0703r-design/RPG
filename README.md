# 🎲 Mestre Arcano RPG

Uma central de RPG de mesa construída com React, TypeScript e Vite, reunindo **Mestre de IA, fichas, bestiário, macros, biblioteca de mídia, NPCs, campanhas e mesa virtual** em uma única aplicação.

## ✨ Recursos

- 🤖 Mestre Arcano com IA para consulta e condução de aventuras
- 📜 Fichas de personagem
- 💀 Bestiário e blocos de estatísticas
- 🎲 Rolagem de dados e macros
- 🗺️ Battlemap/VTT e rastreador de iniciativa
- 👥 Gerenciamento de campanhas e NPCs
- 📚 Base de conhecimento personalizada
- 🖼️ Biblioteca de mídia e visualizador de imagens
- 📊 Relatórios
- 💾 Persistência local dos dados do jogador
- 🛡️ Error boundary para evitar que uma falha de componente derrube toda a aplicação

## 🧰 Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Express
- Google Gemini SDK
- Lucide React
- Motion

## 🚀 Desenvolvimento

```bash
npm install
npm run dev
```

## 📦 Build de produção

```bash
npm run build
npm start
```

## 🔐 Variáveis de ambiente

As credenciais da IA devem permanecer no servidor. Nunca coloque chaves secretas diretamente em componentes React ou em variáveis `VITE_*`.
